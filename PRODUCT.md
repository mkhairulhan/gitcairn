# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers managing multiple local Git repositories across their machines, needing rapid zero-latency inspection, markdown/README reading, repository status checks, file navigation, and safe remote synchronization without heavy web interfaces or full terminal workflows.

## Product Purpose

GitCairn provides a sleek, lightweight local desktop hub (Windows 11 styled) to organize, scan, preview, and update local GitHub/Git projects effortlessly.

## Positioning

A lightweight local repo viewer and manager bridging the gap between raw CLI tools and heavy full-lifecycle Git GUIs (like GitKraken/SourceTree), centered on instant file tree browsing, formatted README viewing, and streamlined repository maintenance.

## Operating Context

- Desktop environment (primarily Windows 11 target).
- Local filesystem containing nested software repositories.
- Local Git CLI and remote origins (GitHub/Git providers).
- Daily developer workspace alongside code editors and terminals.

## Capabilities and Constraints

- Electron + React + Tailwind CSS + Vite stack.
- Multi-folder repository scanning and detection.
- Fast README/markdown parsing and rendering with local media support.
- File tree browsing and file content viewer.
- Git operations: safe pull, check for updates, clone public repos, commit history log.
- Local persistent storage for user preferences and repo metadata.

## Brand Commitments

- Name: **GitCairn**
- Aesthetic tone: Sleek Windows 11 dark mode aesthetic (`#1e1e1e`), fluent-inspired neutral dark palette, clean developer-grade utility.

## Product Principles

1. **Instant Response**: Local actions (scan, read, browse) must feel immediate and low latency.
2. **Safe Operations**: Remote actions (pull, sync) must be predictable, non-destructive, and transparent.
3. **Information Density with Restraint**: Clean readability for code, file trees, and markdown without visual clutter.
4. **OS Harmony**: Align closely with modern desktop conventions (fluent styling, sensible hotkeys, clean chrome).
